# Alessa Sylvanas

Systems administrator and automation-focused software builder. I work across infrastructure, private-source product development, desktop and mobile apps, Unity/VRChat tooling, and AI-assisted workflows.

Most of my product source stays private. Public release repositories under [Sylvanas Labs](https://github.com/sylvanas-labs) show shipping cadence, installers, changelogs, and product notes without exposing source code.

## Currently Shipping

- [Pantheon](https://github.com/sylvanas-labs/pantheon-releases) - creator and agent tooling around Unity, VRChat, Blender, and local development workflows.
- [Karaoke Video Creator](https://github.com/sylvanas-labs/karaoke-video-creator-releases) - Windows desktop pipeline for turning audio, lyrics, and timing data into rendered karaoke videos.
- [VRC Contest Manager](https://github.com/sylvanas-labs/vrc-contest-manager-releases) - local-first desktop tool for running VRChat singing contests.
- [Virtual Eden](https://github.com/sylvanas-labs/virtual-eden-releases) - cross-platform life-management app with Android and Windows release channels.
- [Disk Scout](https://github.com/sylvanas-labs/disk-scout-releases) - Windows disk analysis and cleanup utility.
